## What's Changed in v2.4.98

### Highlights & New Features

- **Gateway View & Affinity Cards**: Card-based gateway probing, session affinity cache-hit topology comparison, one-click BASE URL / header copy pills, and 4-language SDK/CLI snippet switcher (Bash, PowerShell, Node.js, Python).
- **Top Bar Settings Gear & Win32 Tray**: Replaced top-bar power button with settings gear (`Ctrl+,`), added `/api/open-data-dir`, 9-frame High-DPI ICO tray icons (`LoadImageW` `SM_CXSMICON`/`SM_CXICON`), PWA icons (`icon-192.png`/`icon-512.png`), and modern Win32 context menu.
- **Android Streaming Transcript, History Replay & Tool Cards**: Real-time delta accumulation, `history/snapshot` content-to-text normalization, collapsible `item/started` + `item/completed` tool output cards with diff coloring, collapsible `<think>` accordion, and turn failure banners.
