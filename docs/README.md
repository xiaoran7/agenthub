# Documentation index

Start with the root `README.md` for local setup and `ARCHITECTURE.md` for the
system map. Use `DEPLOYMENT.md`, `SYNC_PROTOCOL.md`, and `ANDROID_VALIDATION.md`
when deploying or validating a client. Product intent and implementation notes
live in `PRD.md`, `DESIGN_SYSTEM.md`, `TECHNICAL_FEASIBILITY.md`, and
`PITFALLS.md`; release and validation history is retained in `CHANGELOG.md` and
`M4_VALIDATION.md`.
