## What's Changed in v2.4.94

### Highlights & New Features

- **Mobile Companion Cockpit (`apps/android`)**: Multi-device cockpit inspired by [stablyai/orca](https://github.com/stablyai/orca) with virtual terminal accessory row (`Esc`, `Tab`, `Ctrl-C`, arrows) for touch-friendly remote approvals and output inspection.
- **Embedded Runner Web Console Polish**: Animated skeleton shimmer placeholders, elevated sticky top bar (`46px`), and accurate multi-turn `request_count`/`calls` tracking aligned with upstream [magpie](https://github.com/yetone/magpie).
- **CI & GEO Readiness**: GitHub Actions pipeline for Rust 2024 + Node.js 22, full community health files, and `llms.txt` / `llms-full.txt` indexing manifests.
