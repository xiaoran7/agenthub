当智能 Agent（如 Claude Code）高频发起多轮交互时，若请求在不同上游网关 Worker 间漂移，服务端的 Prompt Cache 将被频繁击穿，命中率由 90% 跌落至 0%，大幅增加时延并成倍损耗 Token。

AgentHub Session Affinity 机制 通过在请求头注入 x-session-affinity: <session_id>，促使上游 Magpie 网关将同一会话路由锁定在相同节点上，保障 90% 以上缓存命中率。

跨平台环境变量配置 (Bash / Zsh):
export ANTHROPIC_BASE_URL="http://127.0.0.1:3425"
export ANTHROPIC_CUSTOM_HEADERS="x-session-affinity=agenthub-session-1"
PowerShell 环境变量配置 (Windows):
$env:ANTHROPIC_BASE_URL = "http://127.0.0.1:3425"
$env:ANTHROPIC_CUSTOM_HEADERS = "x-session-affinity=agenthub-session-1"
