Magpie 架构与 Session Affinity 会话亲和性

已激活

当多个智能 Agent 或客户端并发访问 Anthropic 上游时，若请求在不同后端 Worker 之间轮转，会导致服务端的 Prompt Cache 被频繁击穿，命中率从 90% 跌落至 0%，不仅大幅增加等待时延，还会成倍增加 Token 计费。

AgentHub Session Affinity 机制 通过自动在请求头中注入 x-session-affinity: <session_id>，促使上游网关路由器（如 Magpie 或 CC Switch）将同一个会话的推理请求锁定在同一缓存节点上，从而确保 90% 以上的 Prompt 缓存命中率。

跨工具环境变量一键配置 (Bash / Zsh):
export ANTHROPIC_BASE_URL="http://127.0.0.1:3425"
export ANTHROPIC_CUSTOM_HEADERS="x-session-affinity=agenthub-session-1"
PowerShell 环境变量一键配置 (Windows):
$env:ANTHROPIC_BASE_URL = "http://127.0.0.1:3425"
$env:ANTHROPIC_CUSTOM_HEADERS = "x-session-affinity=agenthub-session-1"
