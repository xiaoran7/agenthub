            Claude Code 官方 CLI
            零修改透明生效
          

        

        
在终端启动 Claude Code 前导出 ANTHROPIC_BASE_URL 环境变量即可自动挂载会话亲和保护层。

        
export ANTHROPIC_BASE_URL="http://127.0.0.1:4200"

      


      

        

          ⚡
          

            Codex / OpenCode
            自定义请求头透传
          

        

        
在客户端网络设置或 config.json 中注入自定义标头 x-session-affinity: <session_id>，保障会话独立。

        
"headers": { "x-session-affinity": "sess-xyz" }

      


      

        

          🤖
          

            多智能体协同集群 (Subagents)
            群组亲和树传递
          

        

        
子智能体派生时继承父会话的 Affinity Tag，所有 Agent 并发或流式步骤共享一份高命中 Prompt Cache。

        
client.headers["x-session-affinity"] = rootSessionId
